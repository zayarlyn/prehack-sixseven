## Folder structure — Frontend (apps/web/src)

Every feature lives in its own module folder under src/modules/:

- `modules/<feature>/pages/` — page-level components, one per route
- `modules/<feature>/components/` — feature-specific components
- `modules/<feature>/hooks/` — React Query hooks and Firebase hooks

Shared code lives in src/common/:

- `common/components/` — shared components used across modules
- `common/components/ui/` — shadcn auto-generated, never edit manually
- `common/lib/` — axios instance, firebase client, queryClient, utils
- `common/hooks/` — hooks used across multiple modules

Never import a module's internal component from another module.
Always import shared components from common/components.
Never write axios calls directly in components — always use a hook.
Never use localStorage directly in components — go through the auth store.

## Frontend patterns — always follow these exactly

### React Query hooks

All server state lives in hooks, never in components:

```typescript
// hooks/useItems.ts
import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';
import api from '@/common/lib/axios';

export const useItems = (query: ItemQueryInput) => {
  return useQuery({
    queryKey: ['items', query],
    queryFn: () => api.get('/api/items', { params: query }).then((r) => r.data),
  });
};

export const useCreateItem = () => {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: (data: CreateItemPayload) => api.post('/api/items', data).then((r) => r.data),
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['items'] });
    },
  });
};
```

Never call axios directly in a component.
Always invalidate relevant query keys on mutation success.
Always handle isLoading and isError states in page components.

### Axios

Always import the configured axios instance:

```typescript
import api from '@/common/lib/axios';
```

Never import axios directly — never write `import axios from 'axios'` in feature code.

### Auth store

Always read auth state through the useAuth hook:

```typescript
import { useAuth } from '@/modules/auth/hooks/useAuth';
const { user, isAuthenticated } = useAuth();
```

Never read from useAuthStore directly in components.
Never read localStorage for token in components.

### TanStack Router

Always use typed hooks with the from option:

```typescript
import { useParams, useNavigate } from '@tanstack/react-router';
const { itemId } = useParams({ from: '/items/$itemId' });
const navigate = useNavigate();
```

Never use window.location for navigation.

### Components

Always define TypeScript interfaces for props:

```typescript
interface ItemCardProps {
  item: Item;
  onClick?: () => void;
}

export default function ItemCard({ item, onClick }: ItemCardProps) { ... }
```

Never use React.FC — use plain function declarations.
Never use default exports for hooks — always use named exports.
Always use default exports for components and pages.

### Tailwind and shadcn

Always use the cn() helper for conditional classes:

```typescript
import { cn } from '@/common/lib/utils';
<div className={cn('base-class', condition && 'conditional-class')} />
```

Never use inline style objects except for dynamic values that cannot be expressed in Tailwind.
Never edit files in common/components/ui/ — these are auto-generated by shadcn.
Always use shadcn components for UI primitives (Button, Dialog, Input, etc).

### Design tokens

Always use CSS variable-based Tailwind classes for brand colors:

```typescript
// correct
<button className="bg-primary text-primary-foreground hover:bg-primary/90" />

// wrong — never hardcode hex values in className
<button className="bg-[#fa4617] text-white" />
```

## Always check common before writing anything new

- `apps/web/src/common/components/` — shared UI components
- `apps/web/src/common/components/ui/` — shadcn primitives (Button, Input, Dialog, etc)
- `apps/web/src/common/hooks/` — shared hooks
- `apps/web/src/common/lib/` — axios instance, firebase client, queryClient, cn() utility

| Need                                                                       | Import from                              |
| -------------------------------------------------------------------------- | ---------------------------------------- |
| Any UI primitive (button, input, dialog, badge, card, tabs, avatar, toast) | `@/common/components/ui/<component>`     |
| Item card                                                                  | `@/common/components/ItemCard`           |
| Item card loading skeleton                                                 | `@/common/components/ItemCardSkeleton`   |
| Empty state                                                                | `@/common/components/EmptyState`         |
| Error state                                                                | `@/common/components/ErrorState`         |
| Loading spinner                                                            | `@/common/components/LoadingSpinner`     |
| User avatar                                                                | `@/common/components/UserAvatar`         |
| Status badge (active/sold/purchased)                                       | `@/common/components/StatusBadge`        |
| Confirm delete dialog                                                      | `@/common/components/ConfirmDeleteModal` |
| Top navigation bar                                                         | `@/common/components/NavBar`             |
| Axios instance                                                             | `@/common/lib/axios`                     |
| Firebase client                                                            | `@/common/lib/firebase`                  |
| React Query client                                                         | `@/common/lib/queryClient`               |
| cn() class helper                                                          | `@/common/lib/utils`                     |

- Never create a new Button, Input, Modal, Spinner, Card, Badge, or Avatar component — shadcn already has these in common/components/ui/
- Never create a new axios instance — import from common/lib/axios
- Never hardcode #fa4617 or any hex color in JSX className — use Tailwind token classes
- Never edit files in apps/web/src/common/components/ui/
- If something you need does not exist in common yet, create it there first and then import it
